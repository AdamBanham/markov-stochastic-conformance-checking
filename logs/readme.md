# Event logs

Make sure to add the following events log to this directory

- `bpic_2020_permits.xes`: BPIC 2020 (permits) log.
    - available @ https://data.4tu.nl/articles/_/12718178/1
- `road_fines.xes`: the road fines event log.
    - available @ https://data.4tu.nl/articles/dataset/Road_Traffic_Fine_Management_Process/12683249/1
- `sepsis.xes`: the sepsis event log.
    - available @ https://data.4tu.nl/articles/dataset/Sepsis_Cases_-_Event_Log/12707639/1
